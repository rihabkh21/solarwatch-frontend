# SolarWatch – Dashboard

React + TypeScript dashboard displaying real-time data from the SolarWatch IoT system (ESP32 → MQTT → Firebase).

## Features
- Real-time [production, tension, température...]
- [graphiques, alertes, historique...]

## Stack
React · TypeScript · Firebase · [Vite ?]

## Run locally
1. `npm install`
2. Create a `.env` file with your Firebase config
3. `npm run dev`
